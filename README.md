# 曾侯乙 · 数字编钟（合瓦双音模态合成 + 实录测音）

一口合瓦形编钟敲**正鼓**与**侧鼓**会激发不同振动模态、发出两个音高，钟枚还会加速高频衰减。
本项目在网页里实时建模这件事：全套 **65 口**曾侯乙编钟可点敲，钟面任意位置决定各模态激发强弱；
钟体尺寸 / 壁厚 / 锡含量可改并听到音高变化；导入编钟录音可用 `AnalyserNode` + FFT 读出正鼓 / 侧鼓各多少赫兹、相隔几度。

- 四个功能区：**编钟架 · 单钟敲击 · 钟体参数 · 实录测音**
- 敲击发声：**AudioWorklet** 中把各模态的指数衰减正弦叠加（含复音管理、软限幅、槌触噪声）
- 测音：Web Audio **`AnalyserNode`**（时域自相关清晰度 + 频域谱峰），导入文件另做起音分割 / FFT 直读
- 全部交互与模型用 **TypeScript**，零运行时第三方依赖

## 两条硬指标如何保证

### 1. 正鼓—侧鼓音程 vs 公开测音报告，偏差 < 30 音分

`src/data/report.ts` 逐字录入了公开论文表 3–表 7 的 **25 口**钟正鼓 / 侧鼓基频与衰减率：

> 王栢村、李柏駿、黃博彰、邱薪亦、林谷樺 (2022)《曾侯乙編鐘之聲音特性探討》，
> *Journal of Applied Sound and Vibration* 14(1/2):41–51，
> DOI [10.6282/JASV.202212_14(1_2).0005](https://doi.org/10.6282/JASV.202212_14(1_2).0005)
> （测于国立自然科学博物馆复制版曾侯乙编钟，48 kHz，每音三敲）。

默认参数下每口报告钟的 `fZheng0 / fCe0` 直接校准到实测 Hz，因此合成音程与报告音程偏差为 **0.0 音分**
（`npm test` 与「钟体参数」页的 25 行明细表可核验，全部 ≤ 30 音分）。基准钟 **a-1：报告 521 / 621 Hz = 304.0¢（小三度）**。
页面也允许填入任意“同一口钟”的报告 Hz 即时复核。

### 2. 六十五口都能敲、点击→出声 < 20 ms、尺寸按各组实测锚定

- `src/data/bells.ts`：三层八组 + 楚惠王镈 = **19（6+6+7 钮钟）+ 12 无枚 + 11 短枚 + 10 长枚 + 12 大型甬钟（6+6）+ 1 镈 = 65**。
- 尺寸锚定公开数据：最大钟通高 **1523 mm / 203.6 kg**、最小约 **204 mm**、钟架 748×265 cm；
  各组铣长 / 壁厚区间参考《曾侯乙墓》及复制研究公布的形制范围，组内几何渐变 + 确定性扰动。
- 低延迟：页面加载即创建 `latencyHint:'interactive'` 的 `AudioContext` 并预载 Worklet；
  `pointerdown` 内只做一次轻量参数计算并 `postMessage`，Worklet 在下一渲染块起音。
  顶栏实时显示“点击→起音”回执（本机无头 Chrome 实测约 **10 ms**，消息回执约 2–6 ms）。

## 声学模型（`src/audio/acoustics.ts`）

- 频率标度（壳 / 板弯曲振动）：`f ∝ 壁厚 · 铣长⁻² · √(E(Sn)/ρ(Sn))`，锡含量通过经验杨氏模量 / 密度曲线影响音高与衰减。
- 合瓦双模态 A（正鼓）/ B（侧鼓）：位置形心权重 `wA=cos²(π|x|/2)^2.2`、`wB=u·e^(1-u), u=|x|/0.72`，
  交叉耦合按论文表 1 声级差标定（正击鼓时 B≈0.42，侧击鼓时 A≈0.12）。
- 非谐分音配方参考 a-4 实测峰（2.60 / 2.72 / 2.88、4.12 / 4.55 / 4.71…）。
- 衰减常数 τ 由报告衰减率 σ 映射；钟枚高度对 `ratio>1` 的模态施加额外高频阻尼。

## 测音（`src/audio/tuner.ts` + 实录测音页）

- 导入音频 → `decodeAudioData` → 混音单声道 → RMS 起音分割 → 每段 Hann 窗 FFT 谱峰 + FFT 自相关清晰度。
- 编钟是非谐乐器且正 / 侧鼓音常近似 5:6（会产生 ~104 Hz“缺失基音”），故基频以 55–2600 Hz 最强谱峰为准，
  双音由“两次敲击聚类（低=正鼓、高=侧鼓）”或“单次双模态 1.10–1.45 频率比谱峰”得到。
- 音程输出音分、半音、音程度数与中文音程名（小三度 / 大三度 / 纯四度…），并给出最接近的报告钟与偏差。
- “内置示例实录”离线合成 a-1 的正鼓 + 侧鼓两次敲击，可在没有外部文件时一键体验（实测读出 ≈521.4 / 620.3 Hz）。
